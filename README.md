# 直齿圆柱齿轮参数化实验室（Spur Gear Lab）

纯浏览器、无后台的教学工具：用 Vue 3 + TypeScript 提供参数输入，Three.js 显示三维齿形与运动，
Clipper2 的 WASM 版本做实体轮廓布尔求交（局部干涉），IndexedDB 保存案例。

用于让学生看清 **齿数 z、模数 m、压力角 α** 如何影响一对直齿轮的尺寸、齿形与啮合。

## 启动

```bash
npm install
npm run dev        # 开发服务器
npm run build      # 类型检查 + 生产构建（dist/，可直接静态托管）
npm test           # 解析尺寸 / 齿形闭合 / 啮合相位 / 导入导出往返 的数值核对
```

## 模型适用范围（重要）

- **仅外啮合**、**无变位**、**理想刚性** 的一对标准渐开线直齿轮；
- 刀具系数：齿顶高系数 ha*=1、顶隙系数 c*=0.25、齿根圆角 ρf*≈0.38（教学近似）；
- 默认标准中心距 a₀=m(z₁+z₂)/2 安装（理论无侧隙）。允许改中心距以**观察**侧隙/顶隙变化，
  此时给出实际啮合角与侧隙，但属于有侧隙安装，不再是无侧隙正确啮合；
- 不考虑弹性、摩擦、热膨胀、制造误差、动载荷；齿廓为端截面 2D 挤出；
  不含斜齿轮、内齿轮、变位齿轮；
- 当 z < z_min = 2/sin²α（α=20° 时 ≈ 17.10）会标红提示**根切风险**；齿廓仍闭合可用，
  但根部为简化几何，仅示意，不代表真实可制造齿形。

## 渐开线公式与范围

基圆半径 r_b = r·cosα，分度圆 r=mz/2。展开参数 t（滚动角）下：

```
x(t) = r_b (sin t − t cos t)
y(t) = r_b (cos t + t sin t)
向径 R(t) = r_b√(1+t²)，压力角 α_t 满足 t = tan α_t
展角（渐开线函数）inv(α) = tan α − α
```

- t∈[0, t_a]，t_a=√((r_a/r_b)²−1)；**基圆以内无渐开线**（用径向线 + 刀具圆角过渡）。
- 齿面构造旋转角 β = π/(2z) + inv(α)；齿顶单侧半角 = π/(2z)+invα−invα_a（即教材 s_a 公式）。

## 为什么不是"按转速比旋转就算正确啮合"

速比 ω₂/ω₁ = −z₁/z₂ 只是**必要条件**。本工具的装配同时保证：

1. 两轮模数、压力角相等 → 基节 p_b=πm·cosα 相等（界面有检查）；
2. **相位正确**：节点 P 处两轮接触齿面共法线（沿啮合线）。接触的是轮1 左齿面 / 轮2 右齿面；
3. 沿啮合线滚动时始终是**同一条渐开线**接触。由几何严格推导（见 `src/geometry/mesh.ts` 注释）：

```
t1 = tanα′ + s/r_b1,  t2 = tanα′ − s/r_b2
dφ1/ds = +1/r_b1,  dφ2/ds = −1/r_b2
⇒ r_b1·Δφ1 = −r_b2·Δφ2   （外啮合反向）
```

`npm test` 的 `check-mesh.ts` 用解析渐开线逐点核对：接触点同时落在两轮齿面上、转角比恰为
−z₁/z₂、转向相反、r_b1·Δφ1=−r_b2·Δφ2。

## 功能

- **暂停**：停在任意位置，拖"接触点 s"滑块沿理论啮合线检查接触位置（齿轮转到严格对应相位）；
- **局部干涉**：暂停后用 Clipper2 WASM 对当前帧两轮实体轮廓求交，红色高亮重叠区并给面积；
- **啮合周期回放**：见下节，沿真正的重复周期逐帧追踪齿对与风险；
- 参考圆（节圆/基圆/齿顶/齿根）、理论啮合线（灰）与实际啮合段（绿）、节点、接触点可切换；
- **单位切换** mm/cm/m/in 只改显示换算，内部始终存 mm，实际尺寸不变；
- 中心距、啮合角 α′、节圆、侧隙、顶隙、重合度 ε_α、基节一致性、根切/变尖检查实时显示；
- **案例**：IndexedDB 本地保存/载入；可导出自描述 JSON（可勾选附带轮廓多边形、已完成周期轨迹），
  导出文件可重新导入，且随载轮廓可直接用于 Clipper 求交（`check-roundtrip.ts` / `check-replay.ts` 验证）。

## 啮合周期回放（为什么不是“按转速比跑一圈”）

单帧暂停只能告诉你“此刻有一个接触点”，而回放要回答的是：**完整啮合一周内，究竟是哪对齿在接触、
什么时候会发生风险**。实现见 `src/geometry/replay.ts`：

1. **真正的重复周期**由啮合线滚动距离决定，而不是某一轮转一圈：
   ```
   Q = N·p_b，  N = lcm(z1, z2) = z1·z2 / gcd(z1,z2)
   ```
   20/40 → N=40（轮1 两圈、轮2 一圈后同一齿对回到原位）；互质 19/31 → N=589，
   周期内遍历全部 589 对齿，**不会提前重复**。

2. 用全局展开量 q 参数化相位；每一帧的两轮角度直接由严格相位公式给出（连续、不折叠）：
   ```
   φ1(q) = φ1⁰(0) − q/rb1，  φ2(q) = φ2⁰(0) + q/rb2
   ⇒ rb1·Δφ1 = −rb2·Δφ2（同一条渐开线接触，非仅转速比）
   ```
   帧内同时在接触的齿对 j 满足 `s_j = j·pb − q ∈ [sE, sX]`，齿序号为
   `k1 = j mod z1，k2 = −j mod z2`；εα>1 时一帧可有多对同时接触。

3. **逐点保存**两轮角度（连续 + 归一）、接触点世界坐标、啮合线位置 s、齿对索引、
   以及 Clipper 对完整实体轮廓的局部干涉结果（面积 + 可定位区域）。

4. Three.js 播放器支持播放 / 暂停 / 回到首帧 / 逐帧步进 / 精确帧号跳转 /
   上一·下一干涉帧跳转；轨迹接触点轨迹（淡绿）与风险相位（红点）画在视图上。

5. **长轨迹计算是有状态的异步任务**：`running / cancelled / failed / completed / expired`。
   分块让出主线程，可随时取消；刷新页面后遗留的 running 自动转 cancelled，
   按**固定帧槽位**覆盖续算（`frameIndices` 保证 IndexedDB clone 后也不错位、不重复插帧）；
   生成期间修改参数 → 任务 expired，帧不会被写为新参数的结果。

6. **持久化绑定案例参数 + 轮廓指纹**：案例改参数后，其历史轨迹在库里标为过期，
   仍可载入回放（界面显示“过期轨迹 · 旧参数”），但不会被标记为当前有效验证；
   导出的 JSON 可附带已完成轨迹，导入时只有**参数指纹与案例完全一致**才关联回原案例；
   没有轨迹字段的案例绝不会被伪造成已验证结果。

`npm test` 中的 `check-replay.ts` 对上述全部验收项做数值/状态机核对。

## 代码结构

```
src/geometry/gear.ts        解析尺寸、渐开线齿廓、闭合外环、输入校验
src/geometry/mesh.ts        装配：啮合角/节圆/侧隙/顶隙/重合度、啮合线、严格啮合相位
src/geometry/replay.ts      啮合周期：真实重复周期、齿对索引、逐帧轨迹、生成器状态机、指纹
src/geometry/clipper.ts     Clipper2 WASM 封装（IntersectD / AreaPathsD）
src/trajectoryStore.ts      轨迹持久化（IndexedDB trajectories store）、空洞安全帧映射、导入校验
src/viewer.ts               Three.js 齿形挤出、参考圆、啮合线/接触点、干涉高亮、回放轨迹
src/store.ts                IndexedDB 与案例 JSON 导入导出（带 schema 版本）
src/units.ts                显示单位换算（内部恒为 mm）
src/App.vue                 参数面板、检查结果、动画/暂停、周期回放播放器、案例管理
scripts/                    数值核对（标准/互质齿数、干涉、状态机、往返与指纹绑定）
```
